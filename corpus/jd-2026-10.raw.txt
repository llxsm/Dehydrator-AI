=== JD-06 AI Agent 开发助理 ===
岗位职责
1. Agent Harness 与编排运行时: 搭建并迭代上下文构造、工具协议、状态与记忆、循环终止条件、失败恢复与重试相关模块; 设计"规划—执行—反思"的 loop，让 Agent 在多步任务中稳定收敛。

4. 上下文与记忆工程: 设计领域知识与样例的注入策略、长上下文压缩与多轮任务状态保持，解决"该给模型的知识没给进去""多轮任务状态丢失"这类决定效果上限的问题。
任职要求
1.本科及以上学历，计算机/人工智能等相关专业；
2.Python 扎实: 能够产出可维护的工程代码；
3.了解 LLM 应用开发: ReAct / plan-and-execute / tool use / memory 中至少一个方向有实际动手经验；
4.较真、细心: 能独立读技术文档并动手复现，有良好的文档习惯；
5.重度使用 AI 编程工具(Claude Code / Cursor / Copilot 等)；
6.能实习3个月以上，每周出勤至少4天。
